## ---- EasyMesh（与中兴 E2637 组有线 mesh，2026-11-13 追加） ----
# prplMesh 6.2.0：Wi-Fi Alliance EasyMesh 标准的开源实现（Controller+Agent 双角色），
# immortalwrt/packages 官方收录（net/prplmesh，openwrt/packages 2026-09 起同源），
# feeds update -a 即可拉到，无需第三方源。
# stock OpenWrt 模式：复用系统 wpad/hostapd（nl80211 + hostapd 控制接口驱动），
# 不替换 WiFi 栈；本机 MT7916（mac80211/mt7915e）无需移植。
# 有线回程优先；BSS 角色在 /etc/config/wireless 用 multi_ap 配置，
# 服务配置在 /etc/config/prplmesh（role=controller 做主路由）。
# 运行时配置步骤见 README 第八节 / 对话记录，固件先只装包不预配。
CONFIG_PACKAGE_prplmesh=y

## ---- prplmesh stock 模式的运行时依赖（必须进 rootfs） ----
# 注意：prplmesh 的 Makefile DEPENDS 不含 wpad/hostapd（只声明 libnl/libopenssl 等库），
# 而基础配置里 wpad-openssl 是 =m（只打包成 apk，不进镜像）。stock OpenWrt 模式
# 运行时完全依赖 hostapd 的控制接口（nl80211 + hostapd ctrl），必须显式装 wpad。
# 选 wpad-openssl（全功能版）：含 EasyMesh 所需的 802.11k/v/r 与 multi_ap BSS 支持，
# wpad-basic-* 系列缺 k/v/r，不能用于 mesh。选 openssl 变体与 libopenssl 依赖一致，
# 避免 kconfig 里 mbedtls/wolfssl PROVIDES 冲突。
CONFIG_PACKAGE_wpad-openssl=y
CONFIG_PACKAGE_hostapd-common=y
